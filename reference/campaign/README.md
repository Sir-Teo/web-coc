# Native campaign reference

Extracted September 11, 2026 from Supercell's public client bundle **18.400.21**, fingerprint `7f04bdfdc4124b1f49308423bb8f4aa8b137aae3`, and extended September 20, 2026 with the client's own single-player Challenges. The campaign screen uses this catalog. The runtime adapter supports all 90 Goblin map villages and 13 of the 19 Challenges with their complete source layouts, enforcing their original progression prerequisites; see [CAMPAIGN-RULES.md](../../docs/CAMPAIGN-RULES.md) for the late families, the Challenge interpretations and the six withheld maps. This catalog contains data, not executable game code. Separate [Pumpkin Bomb](../pumpkin-bomb/README.md), [Santa Trap](../santa-trap/README.md) and [Shrink Trap](../shrink-trap/README.md) references document extracted native artwork and evidence.

`generated.json` is **not** part of this extraction: it holds the 47 forged villages that carry the campaign to 150, written by `scripts/generate-campaign-stages.mjs` from the imported data alone. Every entity it places is a `(GlobalID, level)` pair an imported village already places, so it adds no unaudited row. Reproduce with `npm run campaign:generate`; verify with `node scripts/generate-campaign-stages.mjs --check`.

- `catalog.json`: all 103 names, loot amounts, dependency references, recommended Town Halls, defending heroes and original nonempty CSV fields, including continuation rows, plus `withheld`: the six Challenges this game does not ship and why. Building/trap IDs use the explicit native GlobalID, never the table row index.
- `npc-buildings.json`: focused native stats and visual-export fields for Town Hall levels 1–11 (all levels present in the 90 layouts), the passive Goblin Hut and the special Tutorial Cannon.
- `layouts.jsonl`: one JSON object per campaign stage, in map order. Main-village buildings, traps, obstacles and decorations are preserved verbatim, including positions, zero-based levels, defending-unit arrays and mode fields. Alternate/war layouts and unrelated home-save metadata are excluded.
- `runtime.json`: compact runtime catalog, combat tables and scenery metadata, generated from the same pinned sources. Positions are still native; the adapter adds only the two-tile simulation border. Combat entries keep each building's source `BuildingW` as `collision` for sub-tile pathing, and each stage's `lateStates` keeps the current single-player `ammo`, `wp_lvl`, `mode` and `attack_mode_weapon` of its Eagle Artilleries, Scattershots, Spell Towers, Goblin Halls, Goblin Castles, Foreboding Caves and Goblin Boss Hall (war and draft alternatives are excluded).
- `provenance.json`: exact source URL prefix, SHA-256 of every downloaded file and generated artifact, plus a narrowly accepted malformed JSON suffix in `level/npc22.json`. That file contains a complete root object followed by unrelated duplicate home-save fields. All other unexpected trailing content is rejected.

Reproduce with `python3 scripts/import-native-campaign.py`; verify with `python3 scripts/import-native-campaign.py --check`. Raw sources are cached under `output/native-campaign-source`, fetched with verified HTTPS, and checked against the committed hashes on every run. The regular test suite checks the committed artifacts offline.

## Interpretation boundaries

Select the Goblin map by `MapInstanceName = npc1` through `npc90`, and the Challenges by a `CHALLENGE_TH<level>_<army>` record name, not by `SinglePlayer`: that flag also covers events, qualifiers, Builder Base maps and super-troop tryouts, none of which this game imports. A Challenge's Town Hall comes from its record name because `minRecommendedTHLevel` is empty on every one of them. Keep the original record IDs; for example stage 51 is `NPC51` but loads `level/npc49.json`. Multiple dependency rows and branching links must survive import. The dependency list alone does not prove whether every link is required to unlock a branch.

The opening is **Payback**, **Goblin Forest**, **Goblin Outpost**, **Rocky Fort**. Payback contains a special Tutorial Cannon. Goblin Huts appear at stage 2. They are passive buildings: their saved unit arrays are template state, not defending troops. NPC-level alliance defenders belong to a separate mechanic. At stage 51 X-Bows appear. Later levels add Inferno Towers, Eagle Artillery, Scattershots, Spell Towers, Monoliths, the Golden Dragon and M.O.M.M.A, all implemented from their pinned rows. Some native levels contain more than the previous replay limit of 400 buildings; version 27 accepts up to 600. Do not substitute a generic building, discard special defenders, clamp levels or rescale positions to make an unsupported level appear complete.

Current native layout files sometimes retain alternate-layout fields on individual entities. Those fields are preserved for review; the runtime adapter rejects active alternate modes until their semantics are implemented. Native `lvl` values are zero-based. Obstacle/deco IDs and footprints are preserved. All scenery used by the 90 maps is passable in combat, according to Passable or IsFadedAndPassableInCombat in logic/obstacles.csv and logic/decos.csv. A false base Passable flag must not create a combat barrier when the combat override is true. The source manifest now contains 97 files. Client loot tables establish the initial inventory, not the exact damage-to-loot rounding algorithm or overflow behavior.

Primary sources: [Single Player Attacks](https://support.supercell.com/clash-of-clans/en/articles/single-player-attacks-2.html) documents 90 villages, unlimited attack time, no trophy changes, and star-based progression. [December 2022 update](https://supercell.com/en/games/clashofclans/blog/release-notes/december-update-2022/) added the final 15 villages for TH13–15 and the Mega PEKKA achievement. [TH14 patch notes](https://supercell.com/en/games/clashofclans/blog/release-notes/full-patch-notes-th14-update/) describe displaying the remaining single-player loot in storage buildings.

### Inferno campaign support

Source Inferno placements retain explicit single/multi mode and starting ammunition since battle/replay version 43, which admitted Midnight Oil, All Angle Attack, Burning Sensation and Teamwork Opportunity. See `reference/inferno/README.md` for source interpretation, runtime limitations and verification evidence.

### Late campaign support

Version 44 completes the catalog: every late defense, trap, Goblin building, armed Builder's Hut and garrison roster is implemented from pinned sources, so all 90 villages pass the gate. Each validated `lateStates` entry must match exactly one placement; full ammunition, weapon level 0, bunker mode 0 and a known Spell Tower weapon are required, and anything else keeps its village closed. See [CAMPAIGN-RULES.md](../../docs/CAMPAIGN-RULES.md#late-goblin-map-villages-6290).
