# Defense artwork

Generated September 10, 2026 using the built-in imagegen tool. Each sprite was generated separately with native transparency. Source PNGs are in `art/source/defenses/`; shipping WebPs are in `public/assets/buildings/`. Rebuild with `node scripts/defense-assets.mjs`. The script trims and resizes while preserving the generated alpha; it does not synthesize transparency.
