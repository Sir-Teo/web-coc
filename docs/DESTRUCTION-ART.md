# Destruction artwork

Created September 11, 2026 with the built-in image-generation tool. Accepted RGBA source files are `art/source/ruins/stone.png` and `art/source/ruins/wood.png`. Production assets are `public/assets/environment/ruins-stone.webp` and `ruins-wood.webp`. Both are original artwork, not extracted game assets.

Rebuild with `node scripts/ruins-assets.mjs` or `npm run assets`. The processor validates real alpha, trims transparent margins, preserves aspect ratios, and encodes WebP with lossless alpha. No image service is used when rebuilding.

The renderer uses stone debris for masonry, resource/army facilities and walls; timber debris for barracks, builder huts, camps, archer towers and cannon carriages. It keeps the original world center, draws the pile below live units, and paints a subdued ground scar beneath it. Ruins replace the old vertically squashed intact sprites. These are two shared material families, not bespoke wreckage for every building level.
